# Sample Audio Directory

This directory is reserved for sample audio files used during testing and demonstrations.

## Guidelines

- Large audio files are excluded from version control via `.gitignore` to maintain repository lightness and prevent bloat.
- You can place your own speech recordings or audio clips in this directory for quick testing with the Speech2Text-ASR application.

## Supported Audio Formats

The application supports the following audio formats:

- **WAV** (`.wav`) — Recommended for uncompressed, high-fidelity audio
- **MP3** (`.mp3`) — Common compressed audio format
- **M4A** (`.m4a`) — AAC compressed audio
- **OGG** (`.ogg`) — Ogg Vorbis audio
- **FLAC** (`.flac`) — Free Lossless Audio Codec

## Recommended Audio Characteristics

For best transcription accuracy:
- Clear speech with minimal background noise
- Spoken at a natural pace
- Single primary speaker close to the microphone
