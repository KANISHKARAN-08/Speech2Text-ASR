# Application Screenshots

This directory is designated for storing screenshots of the running **Speech2Text-ASR** application for project reports and repository presentation.

## Recommended Screenshots to Capture

When running the application locally (`streamlit run app.py`), capture and store screenshots of the following user flows:

1. **Home Page**: Initial interface showing header, model selection sidebar, and input options.
2. **Audio Uploaded / Preview**: The UI state when an audio file has been selected, displaying the built-in audio player.
3. **Transcription Result**: The completed speech-to-text output displayed in the result area with detected language.
4. **Download Option**: The download button interaction exporting the transcription as a `.txt` file.

## Placement

Save captured images in this directory (e.g., `01_home_page.png`, `02_audio_uploaded.png`, `03_transcription_result.png`, `04_download_txt.png`) and reference them in documentation or assessment slides as needed.
